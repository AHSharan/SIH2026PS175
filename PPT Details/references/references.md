  Benchmark for Remote Sensing Data", arXiv 2305.14914. Hugging Face `earthflow/GAMUS`, CC BY 4.0.

  via Microsoft Planetary Computer (`3dep-lidar-copc`).
- USDA National Agriculture Imagery Program (NAIP), 0.6 m, US public domain, via
  Microsoft Planetary Computer (`naip`).
